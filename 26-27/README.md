# 26-27 — Team Oceanus Competition Year

Working folder for the **2026–2027** MATE ROV cycle, mirroring the
organizational structure of [`25-26`](../25-26).

## Structure
- `01_Subteams/` — per-subteam working folders (C&C, EPS, F&P, GNC, Outreach,
  TMS) plus `Research Notes/` split the same way.
- `02_Workshop Notes/`
- `03_Competition Specifics/`
- `04_Financial Files/`
- `05_Presentations/`
- `06_Past Teams/`
- `07_Templates/`
- `08_Photos/`
- `Deliverable Documents/`

The `.gitkeep` files just let git track the (currently empty) folders — delete
them once a folder has real content. Dated sub-folders (CAD revisions, weekly
research notes, prototype photos, etc.) get added under these as the year goes,
the same way they did in `25-26`.

> The GNC software from 25-26 (ArduSub SITL kit + photogrammetry app) still
> lives under `25-26/01_Subteams/GNC/`. Carry it forward here when active work
> moves to the new cycle.
